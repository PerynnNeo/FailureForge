# A frozen stiffness prediction and an independent physical measurement

FailureForge predicted **0.029957 N/m** for the 600 µm member of die W2 30 D. NIST measured **0.02868 ± 0.00024 N/m** with an electrostatic force balance. The prediction was **4.45% high**, outside the published standard-uncertainty interval of 0.02844–0.02892 N/m. The value describes a previously measured physical specimen. The 2023 NIST update corrected an equation in Appendix C and retained the Table 1 values used here. [NIST study, Table 1 and Appendix C](https://doi.org/10.6028/NIST.SP.260-227-upd1) · [Frozen prediction and recorded measurement](physical-trial.json)

On the pilot PC, open the saved run and expand **Check against a physical trial** to see the model, assumptions, evidence source and residual. On a fresh installation, create a **Strength & deformation** project, import the reference JSON from **Discover scenarios**, and open the resulting run in **View replays**. Under **Freeze a prediction**, choose **Free-end transverse stiffness**. Record the specimen and fixture before using **Record a physical measurement**. Choose **Existing measurement or published experiment**, enter the EFB value and standard uncertainty, and select the free-end station. The model used nominal geometry, an estimated finished thickness, an assumed bending modulus and a rigid clamp. Thickness enters the beam stiffness cubically. An independent specimen thickness measurement would help distinguish a geometric discrepancy from fixture or material effects. This comparison leaves those possible causes open. It assigns the reported uncertainty to the physical reading only.
